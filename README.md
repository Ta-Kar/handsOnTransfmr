# Hands-on Transformer

An educational implementation of a small Transformer architecture using PyTorch.

## Project goals

The goal is to build a compact, CPU-friendly Transformer that makes the internal architecture of neural networks transparent and easy to experiment with.

The project focuses on:

- Understanding self-attention and Q/K/V projections.
- Exploring multi-head attention and feed-forward layers.
- Studying the effects of model width, depth and number of attention heads.
- Measuring model accuracy, parameter count and training speed.

## Initial task

Text classification using a small Transformer trained from scratch.

The first proposed task is binary sentiment classification.

## Future directions

- Machine translation.
- Biological sequence classification.
- Experiments with different model configurations and sequence lengths.
